# Raw Asset Sources & Original Downloads

This directory holds raw unoptimized downloads, high-resolution source maps, original audio recordings, and CAD/3D source files during autonomous runs.
Individual raw downloads in this directory are untracked by git (via `.gitignore`) to protect repository size.
All production assets are optimized (`gltf-transform`, WebP compression, audio normalization) and committed to `public/` or `src/`.
